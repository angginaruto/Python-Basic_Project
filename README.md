# Cafe Sonntag

Simple cashier system built with Python for managing cafe menus and customer transactions through the terminal.

## Features

* View coffee and non-coffee menus
* Add new menu items
* Edit menu items and prices
* Delete menu items
* Process customer orders
* Calculate total payment
* Calculate change

## Menu

### Coffee

* Espresso — Rp15.000
* Cappuccino — Rp20.000
* Latte — Rp25.000

### Non-Coffee

* Teh — Rp10.000
* Jus — Rp15.000
* Soda — Rp12.000

## Technologies

* Python
* NumPy

## Concepts Used

This project uses several basic Python concepts:

* Dictionary for storing menu data
* Functions for organizing program logic
* Lists for storing customer orders
* NumPy arrays for storing order quantities
* `if`, `elif`, and `else` for handling conditions
* `for` and `while` loops
* Input and output through the terminal

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Go to the project directory:

```bash
cd <project-folder>
```

Install NumPy:

```bash
pip install numpy
```

Run the program:

```bash
python main.py
```
